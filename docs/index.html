About

Claude Code and Codex CLI talk to their model APIs constantly, but that traffic is invisible by default. LLM Visualizer sits transparently in the request path, logs every exchange — headers, JSON body, and every individual SSE chunk for streaming responses — and renders it as something you'd actually want to read: grouped into sessions, diffable turn-to-turn, with tool calls shown as structured cards instead of raw JSON.

Features

Session grouping

Derived from a native session signal where the CLI provides one, falling back to message-history prefix matching within an idle-timeout window.

Three views per exchange

Diff (what changed since the last turn), canonical (normalized, human-readable), or raw (actual request/response JSON and SSE chunks).

Tool calls as cards

A tool_use block renders as a name/ID/arguments table, linked to its matching tool_result, with errors visually flagged.

Collapsible by design

Every exchange and section within it collapses independently, so a 37-exchange session stays scannable instead of a wall of JSON.

Provider-agnostic

Anthropic and OpenAI-shaped payloads both normalize into one canonical schema before rendering, diffing, or usage tracking.

Storage as a port

A small storage interface, currently backed by SQLite, keeps the door open for other backends without rewriting the app.

Quick start (Docker)

docker compose up --build

Builds and runs both services: the proxy on http://localhost:8317 and the viewer UI on http://localhost:5317, sharing a named volume so the SQLite file the proxy writes is the one the viewer reads.

Point Claude Code at it:

export ANTHROPIC_BASE_URL=http://127.0.0.1:8317
claude

Or Codex CLI:

export OPENAI_BASE_URL=http://127.0.0.1:8317
codex

Then open http://localhost:5317. Both can point at the same running proxy instance at once — it forwards based on the detected request shape.

Architecture

packages/ ├── canonical/ # Provider-agnostic request/response schema + normalizers └── storage/ # Storage port + SQLite implementation (exchanges, chunks) apps/ ├── proxy/ # Logging reverse proxy in front of the model API └── viewer/ # tRPC API + React/Vite UI

The proxy forwards every request upstream unmodified and tees a copy to storage on the way through — no change required to how Claude Code or Codex CLI behaves.
